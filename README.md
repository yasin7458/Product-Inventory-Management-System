# 💾 LocalStorage Structure

The application stores data using multiple LocalStorage keys.

| Key | Description |
|------|-------------|
| products | Stores all products |
| addProductStorage | Last added product |
| editProductStorage | Last edited product |
| deleteProductStorage | Last deleted product |
| sortStorage | Sorting preference |
| searchStorage | Search keyword |
